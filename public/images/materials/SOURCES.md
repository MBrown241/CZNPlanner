Class manual images are individual item icons from the same Game8 index. When a class-specific icon is not available locally, the UI currently reuses the Hunter icon of the same tier so the material still has recognizable book artwork. Shared class-manual totals use the same tier-based fallback because their class is unknown.

Passion, Instinct, and Order Growth Stone icons were downloaded from Gacha.gg's original item image paths (`icon_item_card_levelup_love_*`, `icon_item_card_levelup_instinct_*`, and `icon_item_card_levelup_norms_*`) and are stored locally as transparent WebP files. Their rarity-colored frames are styled in the app to match the other growth stone icons. Justice and Void Growth Stone icons are local PNG files.
